# 固定印刷設定（土木課C4476R）

Excelの `frmSeal` からシールを印刷する場合だけ、各PC・各Windowsユーザーが事前登録した `土木課C4476R` のDEVMODE全体を一時適用して印刷します。印刷後は、通常印刷で使用していた処理前のプリンター設定とExcelの `Application.ActivePrinter` へ戻します。

## 各PCでの初回登録

1. Windowsで `土木課C4476R` を所定の設定（トレイ5・手差し、普通紙、片面、ソート、ホチキスなし、パンチなし、排出先指定なし等）にします。
2. Excelで `frmSeal` を開きます。
3. `このPCの印刷設定を登録` を押します。
4. 登録完了メッセージで、プリンター名、コンピューター名、Windowsユーザー名、登録日時、保存先を確認します。
5. 必要に応じて `固定印刷設定をテストする` を実行し、紙を出さずに適用・復元を確認します。

## 通常運用

1. 単件または複数のシール内容を反映します。
2. `固定設定で印刷` を押します。
3. 値が反映されているシートが自動判定されます。
4. 登録済みのプリンター設定で印刷されます。
5. 印刷後は、印刷前の通常設定へ自動的に戻ります。

## 印刷対象

- 単件: `個別フォルダシール`
- 複数: `個別フォルダシール（複数）`

`個別フォルダシール（複数）` は、既存処理で設定済みの `PrintArea` と `PageSetup` をそのまま利用して `targetSheet.PrintOut` します。2ページ・3ページ以上でも、現在設定済みの印刷範囲全体が印刷されます。固定印刷処理では、FitToPagesTall、改ページ、印刷範囲を再計算しません。

## 再登録が必要な場合

- PCを交換した
- Windowsユーザーが変わった
- プリンタードライバーが更新された
- 固定したい印刷設定を変更した
- LOCALAPPDATA内の登録ファイルを削除した

## 保存先

固定印刷設定は、共有フォルダやExcelブック内ではなく、各PC・各WindowsユーザーのLOCALAPPDATAへ保存します。

```text
%LOCALAPPDATA%\file-index-sync\固定印刷設定\土木課C4476R.dat
```

既存ブック内のVeryHiddenシート `_固定印刷設定` が残っていても削除しませんが、今後の登録・読込みには使用しません。

## frmSealへ追加するボタン

リポジトリにはUserFormの画面配置情報（`.frm` のデザイナ情報）が含まれていないため、ボタンそのものはVBEで手動追加してください。コード側のClickイベントは `frmSeal_` に追加済みです。

### ボタン1

- オブジェクト名: `btnRegisterFixedPrint`
- Caption: `このPCの印刷設定を登録`
- 推奨Width: `150`
- 推奨Height: `24`
- 推奨Left: `560`
- 推奨Top: `420`
- Clickイベント: `固定印刷設定を登録する` を呼び出します。

### ボタン2

- オブジェクト名: `btnFixedPrint`
- Caption: `固定設定で印刷`
- 推奨Width: `150`
- 推奨Height: `24`
- 推奨Left: `560`
- 推奨Top: `450`
- Clickイベント: `固定設定で印刷する` を呼び出します。

### VBEでの追加手順

1. VBEで `frmSeal` を開きます。
2. ツールボックスからCommandButtonを2つ配置します。
3. 上記のオブジェクト名、Caption、Width、Height、Left、Topを設定します。
4. `frmSeal_` のコードをフォームコードへ反映します。
5. 既存の通常印刷ボタンは変更せず、そのまま残します。

## エラー時の安全動作

- 登録ファイルが存在しない場合は印刷しません。
- 登録ファイルが破損している場合は印刷しません。
- 別PCまたは別Windowsユーザーの設定ファイルをコピーした場合は印刷しません。
- プリンタードライバーが登録時から変わっている場合は印刷せず、再登録を案内します。
- 単件用・複数用の両方に印刷データがある場合は、安全側で印刷を中止します。
- Cleanupでは、対象プリンターのDEVMODE、`Application.ActivePrinter`、`ScreenUpdating`、`EnableEvents`、`DisplayAlerts`、`PrintCommunication`、`CutCopyMode` の復元を試みます。

## プリンター検索の診断

対象プリンターが見つからない場合や、`ServerName` / `PortName` の表記を確認したい場合は、Publicマクロ `固定印刷プリンター診断` を実行してください。`Win32_Printer` から名前に `土木課C4476R` を含むプリンターを抽出し、診断シート `固定印刷プリンター診断` に `Name`、`ServerName`、`PortName`、`DriverName` を出力します。

プリントサーバーは `PRTSV03.sojanet.local`、`PRTSV03`、`\\PRTSV03` などの表記揺れを正規化して同一サーバーとして判定します。ただし、プリンター名に `土木課C4476R` を含む条件は維持し、複数候補がある場合は自動選択せず印刷を中止します。
