# BUD-151 実機検証（未検証）

必ずマクロ付きブックとCSVの検証用コピーを使う。本番データや本番システムに取り込まない。VBAを同期し、VBEの「デバッグ」→「VBAProjectのコンパイル」を実行する。失敗時はメッセージと対象行を記録し、保存せず閉じる。以下の期待結果は実機合格の主張ではない。

## 事前準備
- 「目録CSV」と「新ファイル基準表」に、それぞれ年度（和暦）がR7・R8・R9の検証行を用意。R7=2025、R8=2026、R9=2027。必要な場合、既存のExcel管理行ID等は所定の方法で発行し、正式な見出し・識別値を使う。
- R7・R9行の全セル値、式、表示値、背景色、表示形式、入力規則をコピーに記録する。行番号は新規行の挿入で変わるため管理行IDでも照合する。
- まず「CSV整形」すなわち `手順2_新ファイル基準表を作成する` を対象年度R8で実行する。「CSV整形＋コード更新」はさらに手順3を実行する。コード管理CSVは年度別ではない共通マスタとして扱う。

## 1. 異年度の重複と判断
- 目録CSVのR8行と基準表のR7・R8・R9行に同じファイルID、別のケースで同じバーコード番号、別のケースで同じ名称4項目を設定する。R8行の作成年度はR7のケースも作る。CSV整形をR8で実行し、自動表示または「確認候補を開く」でフォームを表示する。
- 期待: 比較・B候補・A/C/E判断にはR8のみ。作成年度R7のR8行も対象。R7・R9だけの同一識別番号や名称はR8の候補や保留理由にならない。R8内で同じ識別番号を重複させた別コピーでは、従来の重複・矛盾の安全確認が働く。
- 起こり得る不具合: 異年度候補の表示、同年度重複の見逃し、R8行の未表示。フォームの対象年度、行番号、年度（和暦）、3識別番号、名称4項目を記録する。

## 2. D判断とE判断
- R7とR8に同じファイルID／バーコードを持つ行を用意し、R8のD候補を表示して番号クリアの判断を行う。同じR8内に重複を用意した別コピーでも試す。
- 期待: R7との重複だけを理由に保留せず、R8内の重複・識別矛盾は従来どおり確認。E競合を用意し、R8の項目採用・保留後にR7/R9の値と判断履歴を比較する。
- 起こり得る不具合: 異年度の重複による保留、同年度重複の通過、別年度の履歴やセルの変更。フォームのD/E候補、表示年度、対象行、3識別番号、履歴シートを確認する。

## 3. 年度不明・不整合での停止
- 別々のコピーで「目録CSV」または「新ファイル基準表」のデータ行の年度（和暦）を空欄、不正値、または西暦年度と不一致にする。CSV整形をR8で実行する。
- 期待: 更新前に対象シート名・行番号・年度値と空欄／不正／不一致の理由が表示され、2シートのデータは変わらない。対象外シートの年度不明行だけでは、この検査によって停止しない。
- 起こり得る不具合: 行の見逃し、誤停止、通知値の誤り、部分更新。2シートのセルを実行前コピーと照合する。数式が空文字を返すデータ行も別ケースで試す。

## 4. 数式・個別書式と列順
- 列順が既定の検証用コピーの基準表のR7・R9行に、同一シート内および別シートを参照する相対参照・絶対参照の数式を設ける。R7の別セルには背景色、表示形式、入力規則を設定する。参照先・式・計算結果・書式を記録し、R8のCSV整形を実行する。
- 期待: 列並べ替え不要なら処理が進み、R7・R9の式、参照先、計算結果、個別書式および値が変わらない。新規行追加時は行番号の変動に注意して管理行IDで比較する。
- 別コピーでは基準表の見出し列を既定順から入れ替える、または優先表示見出しを不足させた状態でCSV整形する。期待: 列並べ替えや優先見出しの追加が必要な可能性を検出して更新前に停止する。自動列並べ替えの完成を意味しない。
- 起こり得る不具合: 数式が値化、参照先や計算結果・背景色が変化、必要ないのに停止、停止前の部分更新。記録した式と参照先・値・書式、および表示メッセージを確認する。テーブル、結合セル、非表示行・フィルターがあるコピーも試す。

## 5. 追加・削除・関連出力
- R8に追加対象を用意し、R7またはR9に同じ3識別番号を持つ行を別途用意する。R8整形を実行し、新規行がR8のグループへ置かれたこと、R7/R9の行を誤って移動・更新していないことを管理行IDで確認する。
- R8と異年度に削除予定行を用意し、R8整形後の同期状態・削除可否を比較する。差異一覧の年度R8出力も確認する。
- 起こり得る不具合: 異年度行の再特定・移動、重複追加、異年度の削除状態変更、異年度由来の差異や保留。基準表の管理行ID・年度・識別番号・同期状態と出力CSVを確認する。
